# Documentation sources

The published pages combine curated guides with adapted AnubisWatch documentation.
The source repository and pinned commit are recorded in source.json.
Upstream material is licensed under Apache 2.0; LICENSE.txt retains that license.
Reference Markdown is modified for website navigation, presentation and known
command drift. Curated pages are checked against the listed implementation paths.

To update:

1. Read the new README, reference docs, release assets and implementation.
2. Update the Markdown files and source.json together after checking examples.
3. Preserve curated corrections such as archive downloads and MCP tool names.
4. Run npm run build and npm run test:e2e.

Search JSON is generated by scripts/build-docs-index.mjs during build and dev setup.
It is intentionally not committed. Build requires no live upstream network access.
